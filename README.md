# Mello – Service Language Learning

เว็บแอปเรียนภาษาอังกฤษและภาษาจีนสำหรับผู้ทำงานสายบริการ (ผู้ใช้เป็นคนไทย) — 8 หมวดอาชีพ, 64 บท, 320 คำ, สถานการณ์สนทนา 64 สถานการณ์ (5 ขั้น/บท)

หมวด: Hotel, Airline, Restaurant, Tourism, Customer Service, MICE, Spa, Retail

## เริ่มใช้งาน

```bash
npm install
npm run dev          # เปิด http://localhost:5173
```

ใช้ Chrome หรือ Edge (รองรับเสียงอ่านและรู้จำเสียงพูดดีที่สุด) ครั้งแรกให้สมัครสมาชิก (รหัสผ่านอย่างน้อย 8 ตัว มีทั้งตัวอักษรและตัวเลข) ข้อมูลเก็บในเบราว์เซอร์ ไม่ต้องตั้งค่าฐานข้อมูล

## สคริปต์

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | รันโหมดพัฒนา |
| `npm run build` | ตรวจชนิดข้อมูล (tsc) แล้ว build |
| `npm run lint` | ตรวจโค้ดด้วย ESLint |
| `npm test` | เทสต์หน่วย (vitest) |
| `npm run validate:data` | ตรวจข้อมูลบทเรียน ต้องได้ 8 หมวด / 64 บท / 320 คำ (`:partial` ตรวจเฉพาะหมวดที่มี) |
| `npm run e2e` | เทสต์ทั้งระบบด้วย Chrome จริง (ต้อง `npm run build` ก่อน; ตั้ง `CHROME_PATH` ถ้าไม่พบเบราว์เซอร์) |

## ฟีเจอร์

- **10 หน้า:** Login/Register, Home, เลือกภาษา, หมวดอาชีพ, รายละเอียดบท, คำศัพท์, ประโยค & ไวยากรณ์, สนทนา, คำที่ติดดาว, โปรไฟล์ (+ หน้า "ฝึกฝน" เป็นหน้าที่ 11)
- **เรียน:** การ์ดคำศัพท์ พร้อมคำแปลไทย คำอ่านทับศัพท์/พินอิน ประโยคตัวอย่าง ปุ่มฟังเสียงทั้งคำและประโยค ไวยากรณ์ EN/ZH สวิตช์พินอิน (จำค่า) ปุ่มย้อนกลับ/บทถัดไป
- **แบบฝึก 6 แบบ** สร้างโจทย์จากข้อมูลคำศัพท์อัตโนมัติ: จำคำศัพท์, อ่านคำศัพท์, ออกเสียง, ฟังแล้วเข้าใจ, สร้างประโยค, ใช้ในสถานการณ์งาน → หน้าสรุปคะแนนและคำแนะนำ
- **สนทนา:** บทบาท/บริบท 5 ขั้น พิมพ์หรือพูดไมค์ ตรวจความเหมาะสมแล้วแสดงคำตอบแนะนำ
- **XP:** แยกภาษา ได้ครั้งแรกต่อ (ผู้ใช้, ภาษา, บทเรียน) เท่านั้น บังคับในชั้น service
- **คำที่ติดดาว:** แยกแท็บ EN/ZH คงอยู่หลังรีเฟรช
- **โปรไฟล์:** XP/เลเวลแยกภาษา ความก้าวหน้าต่อหมวด สถิติ ประวัติ XP
- **Fallback:** ไม่รองรับเสียงอ่าน/รู้จำเสียง หรือไม่มี voice ภาษานั้น → แจ้งเตือนชัดเจนและใช้การพิมพ์แทน

## โครงสร้างโปรเจกต์

```
src/
  components/      ui/ (Button, Card, ProgressBar, Badge, Modal, Tabs, Toast, IconWord), layout/, WordCard ฯลฯ
  pages/           หน้าทั้งหมด
  features/        auth, settings, learning (progress/XP), practice, conversation, profile
  services/        storage/ (StorageService + Local + Supabase stub), speech, recognition
  hooks/           useProgress, useTtsStatus, useSpeechInput
  data/            <career>/<lesson>.json + careers.ts + validate.ts
scripts/           validate-data.ts, e2e.mjs
supabase/          schema.sql (โครงสำหรับ backend จริง — ยังไม่ผ่านการทดสอบ)
```

## ข้อมูลบทเรียน

ไฟล์ `src/data/<careerId>/<careerId>-NN.json` ต่อบท: คำศัพท์ 5 คำ (`id` และ `category` เติมอัตโนมัติตอนโหลด), ไวยากรณ์ EN/ZH, สนทนา 5 ขั้น (`prompt`, `suggestedAnswers`, `keywords`, `tipTh`) เพิ่ม/แก้บทแล้วรัน `npm run validate:data` — ตัวตรวจจะเช็กฟิลด์ว่าง, จำนวนคำ/ขั้น, id ซ้ำ, พินอินมีวรรณยุกต์, ประโยคตัวอย่างมีคำศัพท์จริง และ keyword ต้องอยู่ในคำตอบแนะนำ

## ชั้นข้อมูลผู้ใช้ (StorageService)

UI เรียกผ่าน interface เดียว `StorageService` (`src/services/storage/`)

- `LocalStorageService` (ค่าเริ่มต้น): เก็บใน localStorage; รหัสผ่าน hash ด้วย Web Crypto PBKDF2-SHA256 150,000 รอบ + salt ต่อผู้ใช้
- `SupabaseService`: **stub** (สลับด้วย `VITE_STORAGE_BACKEND=supabase` ดู `.env.example`) โครงตารางและ RLS อยู่ใน `supabase/schema.sql`

เสียบ AI ตรวจคำตอบสนทนาภายหลัง: ทำ `AnswerEvaluator` ใหม่ใน `src/features/conversation/evaluator.ts` ให้เรียกผ่าน backend ของคุณ — **ห้ามฝัง API key ในโค้ดฝั่งเว็บ**

## ข้อจำกัดที่ควรรู้

- **ความปลอดภัยแบบ local:** hash ทำฝั่ง client และเก็บในเบราว์เซอร์ ผู้ที่เข้าถึงเครื่องอ่านข้อมูลและพยายามเดารหัสแบบ offline ได้ ไม่มี rate limit ไม่ปลอดภัยเทียบ backend จริง ใช้เพื่อสาธิต/ใช้ส่วนตัวเท่านั้น และข้อมูลไม่ซิงก์ข้ามอุปกรณ์
- **รู้จำเสียงพูด** (Chrome/Edge) ส่งเสียงไปประมวลผลที่เซิร์ฟเวอร์ผู้ให้บริการเบราว์เซอร์ ต้องมีอินเทอร์เน็ต; การตรวจออกเสียงเทียบข้อความที่ถอดได้ ไม่ได้วัดคุณภาพเสียงจริง
- **ตรวจคำตอบสนทนาด้วย keyword** เป็นการประมาณ ตอบถูกความหมายแต่ใช้คำอื่นอาจถูกตัดว่าไม่เหมาะสม จึงแสดงคำตอบแนะนำเสมอ
- **เนื้อหา** คำแปลและพินอินเขียนโดย AI ผ่านการตรวจโครงสร้างอัตโนมัติแต่ยังไม่ผ่านผู้เชี่ยวชาญภาษา ควรให้เจ้าของภาษา/ครูตรวจก่อนใช้งานจริง
- **ฟอนต์** โหลดจาก Google Fonts ต้องมีอินเทอร์เน็ต (ถ้าต้องใช้ออฟไลน์ให้ self-host)
